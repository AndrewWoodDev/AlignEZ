# Multi-Objective Alignment Framework

This repository contains scripts and notebooks for analyzing, evaluating, and visualizing the behavior of multi-objective aligned language models.

## Features
- Embedding generation and SVD-based dimensionality reduction
- Multi-objective reward interpolation and evaluation
- Visualization tools for steerability and model behavior
- Toxicity and Truthful QA evaluation pipelines

## Folder Structure
- `multi-objective/`: Core logic and experiments for multi-objective alignment
- `toxicity/`: Scripts for evaluating toxicity across generations
- `truthful-qa/`: Evaluation suite for truthfulness metrics
- `assets/`: Contains sample result visualizations
